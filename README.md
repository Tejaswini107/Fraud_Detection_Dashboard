# AI-Powered Fraud Detection System

## Overview
This project implements an end-to-end fraud detection pipeline using machine learning and explainable AI techniques. The system detects fraudulent financial transactions using supervised and unsupervised models and provides interactive fraud analysis through a Streamlit dashboard.

## Models Used
- LightGBM
- XGBoost
- Isolation Forest

## Explainability
- SHAP Summary Plot
- SHAP Waterfall Plot
- Feature Importance Analysis

## Dashboard Features
- Fraud overview metrics
- Transaction explorer
- Risk tier analysis
- SHAP transaction explanations
- Interactive Plotly visualizations

## Technologies Used
- Python
- Scikit-learn
- XGBoost
- SHAP
- Streamlit
- Plotly
